② Clusters

Clusters are found with the Louvain method. Modularity shows how cleanly the network splits: higher means links are dense inside clusters and sparse between them (around 0.3 or more is usually read as clear structure). Louvain can land on slightly different answers each run, so it is run 10 times and the range is shown. Raising the minimum similarity drops weaker links and leaves out more works, which pushes Q up, so only compare Q values found at the same setting.

Work Similarity

Two works are linked when their hashtags overlap. Similarity (Jaccard) = shared hashtags ÷ all the different hashtags the two works have between them, so 1 means identical hashtags and 0 means none in common.

How to Use the Network Explorer

Filter the network

Use category filters, minimum frequency, and minimum edge weight to control which hashtags and relationships are visible.

Inspect a hashtag

Hover over a node to see its category, frequency, and strongest connections.

Pin nodes

Drag a node to place it; it stays where you drop it. Double-click a node to pin or release it. Click a work node to open its info card. Use Clear all pinned nodes to reset the layout.

Compare tags

Switch to Compare and add two or more hashtags. The comparison layout appears automatically and shows which tags connect to each selected term.

Hide dominant tags

Use Hide Tags to remove very central hashtags, such as 능력녀 or 로맨스판타지, and reveal smaller patterns.

Map by works

Switch "Map by" to Works to turn every work into a node. Works are linked by how much their hashtags overlap; use Color by Hashtag to paint works that carry a hashtag, and Compare to set two or more works side by side.

Analysis

Pick any hashtag as the focus. ① lists the hashtags it is paired with; ② groups works or hashtags into clusters (Louvain) and reports modularity. Both can be downloaded as CSV.

Read the edges

An edge means that two hashtags appear in the same work. A thicker edge means that the co-occurrence appears in more works.
